端面椭圆包络近似法

角度输出精度 0.01°
▶计算依据与适用条件
L = 2·√[ h·(2R − h) ]槽口弓形弦长
S = ρ − √[ ρ² − (L/2)² ]刀具圆在弦长 L 上的矢高，ρ = D/2
α = arcsin( h / S )机头摆动角（刀具轴线与铅垂线夹角）
Δ = max | y椭圆 − yR弧 |近似加工最大间隙
原理：铣头倾斜 α 后，刀具端面圆在垂直于进给方向的投影为一椭圆（长轴 = 刀具直径 D）。椭圆弧与理论圆弧在槽口两点及槽底最低点三点吻合，故可用小于 2R 的定值刀具近似铣出圆弧槽。
适用条件：R > ρ；L < D；h ≤ S（保证 arcsin 有解）；推荐 α ≤ 45°。
刀尖圆弧 r：决定槽底实际成形圆角（r 越大槽底越圆滑），并影响端面平底宽度 D−2r；摆动角由刀具半径 ρ = D/2 按端面椭圆包络确定。
操作：按图示方向扳转铣头至 α → 锁紧 → 对刀（刀具最低点对至槽底深度 h）→ 沿槽长方向进给。
